# Risks — fail-if-missing checklist

Canonical scored rubric: `standards/rubrics/risks.md`.

Human still signs. This generator is Draft-only until QA Manager/Product Owner confirms levels and stopper calls.

Immediate fail:

- Risk with no Basis (no REQ ID, no quoted/paraphrased input fragment)
- Missing Stopper? column or missing Test depth
- Not ranked Critical/High before Medium/Low
- Invented probability/impact number with no stated basis
- Risks presented as confirmed fact rather than draft/candidate
- Generic filler risks padded in when the input gave no basis for that category
